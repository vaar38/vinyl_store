# Магазин виниловых пластинок

Учебный проект по предмету «Создание программного обеспечения».

**Тема** — «Разработка интернет-магазина виниловых пластинок с учётом остатков и оформлением заказов с доставкой».

В магазине будут продаваться только новые виниловые пластинки. В первой версии планируется 8–12 позиций. Заказы доставляются по указанному адресу, оплата при получении.



| Роль | Возможности |
| --- | --- |
| Гость | Просматривать каталог и карточки пластинок. |
| Покупатель | Работать с корзиной, оформлять заказы, смотреть их в личном кабинете и отменять до отправки. |
| Сотрудник магазина | Собирать заказы, передавать их в доставку и отмечать получение. |
| Администратор | Управлять товарами, ценами и остатками. |

В карточке пластинки отображаются обложка, исполнитель, альбом, жанр, цена и доступный остаток.

## Остатки и заказы

- Добавление пластинки в корзину не меняет доступный остаток.
- При оформлении сервер в одной транзакции проверяет и уменьшает доступный остаток, создаёт заказ и фиксирует цену в каждой позиции. Если хотя бы одной позиции не хватает, транзакция откатывается целиком.
- Если два покупателя одновременно оформляют последнюю пластинку, один заказ создаётся, а второй запрос получает HTTP `409 Conflict`.
- Покупатель может отменить заказ до отправки. Отмена и возврат зарезервированного количества в доступный остаток выполняются в одной транзакции.
- При отправке и доставке заказа доступный остаток повторно не уменьшается.
- Изменения остатков записываются в журнал движений, а переходы заказа — в историю статусов. Записи сохраняются в той же транзакции, что и соответствующие изменения.

В заказе сохраняются имя и телефон получателя, адрес и комментарий к доставке, её стоимость и итоговая сумма. Изменение профиля покупателя не меняет данные оформленного заказа.

## Планируемый стек

| Технологии | Назначение |
| --- | --- |
| FastAPI и Pydantic | HTTP API, проверка входных данных и документация OpenAPI. |
| SQLAlchemy, PostgreSQL и Alembic | Работа с данными, транзакции и миграции схемы. |
| React и TypeScript | Интерфейс магазина, личного кабинета и управления заказами и товарами. |
| Docker Compose и Nginx | Запуск сервисов и проксирование запросов к API. |
